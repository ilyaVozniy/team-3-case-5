# Case 5: Food Delivery ETA Regression

This project addresses a regression task: predicting the actual delivery time, in minutes, from the moment a food order is placed until it is delivered.

## Dataset

The model uses the [Food Delivery Orders and ETA Logistics Dataset](https://www.kaggle.com/datasets/razanihababdellatif/food-delivery-orders-and-eta-logistics-dataset).

## Notebook Development

Install the development tools:

```bash
make install
```

Available commands:

```bash
make help
make lint
make format
make clean
```
